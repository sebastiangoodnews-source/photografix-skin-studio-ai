INSTALL (about two minutes)
================================================================

1. Install "Adobe UXP Developer Tool" (free) from the Adobe Creative Cloud
   desktop app, and make sure Photoshop 24.2 or newer is installed.

2. Open Photoshop first, then open UXP Developer Tool.

3. In UXP Developer Tool click "Add Plugin…".

4. Select THIS file from the unpacked download:

       plugin/manifest.json

5. Click "Load".

6. In Photoshop: Plugins > Photografix Skin Studio AI.
   (On some versions it appears under Window > Extensions.)

The plugin works offline and never contacts a server. No account, no key,
no credits, no subscription.

================================================================
ABOUT .ccx / DOUBLE-CLICK INSTALLERS
================================================================

A .ccx is Adobe's signed plugin package format. Producing one that a user can
double-click requires an Adobe-issued signing certificate tied to a publisher
account, created through UXP Developer Tool or the Adobe Exchange pipeline.
That certificate belongs to the publisher and could not be produced in the
environment where this package was built, so this release does not ship a
.ccx: an unsigned .ccx is not installable, and shipping one would only look
like an installer.

This package installs via the documented developer route above, which is the
same route Adobe documents for unsigned/sideloaded plugins. To produce a .ccx
later, open this folder in UXP Developer Tool > Package and sign it with your
own Adobe credentials.

================================================================
FIRST RUN
================================================================

1. Open a portrait photograph.
2. In the panel press "Analyse" so the plugin reads the face and body.
3. Work down the seven stages. "Preview" shows a stage without committing it;
   "Apply stage" commits it. "Build Photoshop layers" writes the whole stack
   into your document as editable layer groups.
4. Nothing is ever flattened. Your original layer stays untouched at the bottom
   of the stack, and every Photografix stage is its own group you can hide,
   reorder or delete.

================================================================
WHAT TO TRY FIRST
================================================================

For a normal portrait retouch the defaults are deliberately conservative:

  Stage 1  Frequency Separation  -> Normal mode, radius 6-10
  Stage 2  Micro Dodge & Burn    -> Very subtle
  Stage 3  Sculpt Dodge & Burn   -> Natural
  Stage 4  African Skin Tone     -> Auto-match on
  Stage 5  Colour Grading        -> your look
  Stage 6  Glossy Skin            -> Subtle glow
  Stage 7  Final Review          -> read the checks, change nothing

Stage 7 measures texture loss, skin-lightness drift, edge halos, clipping and
face-to-body colour matching against your original, and tells you what it
found. If it says PASS, you are done.

================================================================
IF SOMETHING GOES WRONG
================================================================

"Add Plugin" refuses the file
    UXP Developer Tool needs manifest.json at the root of the folder you
    select. If you unpacked twice you may have a folder inside a folder;
    select the inner one so that plugin/manifest.json is the path.

The panel opens but says "Preview mode"
    Photoshop was not running, or the panel was opened in a browser. Launch
    Photoshop and load the plugin again from UXP Developer Tool.

"Build Photoshop layers" does nothing
    It only works with a real document open in Photoshop. On a wrong document
    (32-bit, or a document with no pixel layer) it reports why in the panel.

VERIFICATION, STATED HONESTLY
================================================================

The algorithms, layer model, panel and Photoshop translation layer are covered
by 108 automated tests, including tests that open the packaged zip, parse the
shipped panel.js with module syntax unavailable, and boot it to check that all
seven studios render.

The plugin has NOT been executed inside Photoshop, because no Photoshop host
existed in the environment where it was built. This package does not claim
otherwise. The behaviours only a real host can confirm are listed in
RELEASE_NOTES_v1.0.0.md and docs-09-testing.md, both included:

  - layer-mask descriptor acceptance per Photoshop version
    (a bake-into-pixels fallback exists)
  - wide-gamut / 32-bit document round-trip
  - docked panel layout at the 320x480 minimum size
  - placeEvent throughput and modal timing on very large documents
